# STA_group_004_project
This is the repository for the group project of Statistical Data Analysis for group 004. 

Members of the group are listed below:
Marta Guzmán Alarcón
Rares-Costin Haritonov
Gabriele Bazzanella Bauer

The scope of the project is to analize a dataset for a client that needs us to do the following:
    1 - Characterise the individuals that are present in the data.
    2 - Estimate how much time on average Finnish households spend daily on each activity.
    3 - With respect to which activities do living environments or days of week differ in Finland?
    4 - Which activities are associated with each other in Finnish population?

The information on how data is structured + an explanation of the variables can be found in the file 'habits.txt'
